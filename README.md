# DONG - 金屬管件品質控管與包裝規範手冊 (Metal Pipe Fittings QC & Packaging Manual)

歡迎來到 **DONG** 品質管理倉庫。本文件旨在建立標準化的品質保證 (QA) 與品質控管 (QC) 流程，專門針對金屬管件產品之外觀檢驗、尺寸品檢及包裝規格進行規範。

---

## 1. 核心品質目標 (Core Quality Objectives)
- **零缺陷出貨**：嚴格把關尺寸公差與外觀瑕疵，確保出貨品質。
- **標準化作業**：從進料、製程檢驗、外觀檢測到最終包裝皆有明確標準。
- **完善防護**：確保金屬管件在運輸與儲存過程中的防鏽與防撞安全。

---

## 2. 部門職責與分工規範 (Department Roles & Responsibilities)

### 2.1 全員共同核心能力：外觀檢測 (Visual Inspection)
- **適用對象**：全體成員（品檢、品保、包裝人員）。
- **要求**：所有人皆須具備並落實金屬外觀檢測能力，把關以下瑕疵：
  - 表面刮傷、凹坑、裂紋、沙孔。
  - 毛邊、鏽蝕、氧化皮。
  - 油污或異物殘留。

### 2.2 品檢人員 (Inspectors) - 實質檢驗與尺寸量測
- **職責**：
  - 執行實體尺寸與幾何公差檢驗（外徑、內徑、壁厚、螺牙精度及長度）。
  - 確實填寫「檢驗紀錄表」，判定產品合格與否。

### 2.3 品保人員 (Quality Assurance) - 品質控管與規範維護
- **職責**：
  - 制定與維護品質控管標準、檢驗作業指導書 (SOP)。
  - 追蹤不合格品原因、推動改善對策 (CAPA) 及品質數據統計。

### 2.4 包裝人員 (Packers) - 包裝規格執行與最終把關
- **職責**：
  - 嚴格依照「包裝規格表」執行包裝作業。
  - 執行產品防鏽處理與外觀最終確認，確保無碰撞與受潮風險。

---

## 3. 金屬管件檢驗流程 (Inspection Workflow)
1. **尺寸量測**：使用量具檢驗管件關鍵尺寸與公差。
2. **外觀檢測**：全員參與，檢查表面有無刮傷、毛邊、鏽蝕。
3. **成品驗收**：確認合格後轉交包裝部門。

---

## 4. 不良品判定與處置標準 (Non-conforming Product Judgment & Disposition)
- **尺寸超差**：超出圖面公差範圍者，判定為不良。
- **外觀嚴重瑕疵**：裂紋、穿孔、嚴重鏽蝕或深刮傷者，禁止出貨。
- **處置方式**：返工修復、報廢處理或特採放行。

---

## 5. 包裝規格表 (Packaging Specification Table)

| 項次 | 項目 | 規格與要求說明 | 負責角色 |
| :--- | :--- | :--- | :--- |
| **1** | **防鏽與清潔處理** | 保持管件乾燥清潔；必要時塗抹防鏽油或使用抗鏽包裝紙/PE袋密封。 | 包裝人員 / 品檢 |
| **2** | **內包裝規範** | 依產品尺寸使用合適之塑膠袋分裝，避免運送中互相摩擦碰撞。 | 包裝人員 |
| **3** | **外箱規格與承重** | 採用標準強化紙箱（如 5 層瓦楞紙），單箱總重通常不超過 20kg，避免搬運破裂。 | 包裝人員 |
| **4** | **緩衝與填充** | 箱內空隙須使用氣泡布或緩衝泡棉填滿，防止運輸晃動撞擊。 | 包裝人員 |
| **5** | **標籤與識別規範** | 外箱須張貼清晰標籤，內容包含：<br>• 品名 / 型號<br>• 規格尺寸<br>• 數量 / 淨重 / 毛重<br>• 生產批號 / 製造日期 | 包裝人員 / 品保確認 |
| **6** | **棧板與疊放規範** | 若需棧板出貨，應整齊交錯堆疊，外層使用纏繞膜（PE Stretch Film）固定並加貼防護角。 | 包裝人員 |
